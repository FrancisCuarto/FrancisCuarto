## 🚧 What I'm building

<div align="center">

### 🐋 Orca Teams

**A collaborative workspace where humans and AI agents work together.**

</div>

I'm developing **Orca Teams**, a collaborative fork of Orca that expands the original desktop experience with project-management and team-work features.

- **Kanban boards** to organize work and assign responsibilities.
- **Collaborative whiteboards** for free drawing, diagrams and flowcharts.
- **Shared notes** for project documentation and ideas.
- **Human + AI task assignment:** assign tasks to a teammate or an AI agent.
- **Remote collaboration:** synchronize project work across users and devices.

<sub>Currently in development. The project builds on Orca's existing desktop stack, including TypeScript, Electron, React and Vite. Collaboration, synchronization and agent orchestration are being planned and implemented in stages.</sub>
