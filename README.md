## 🧑‍💻 Sobre mí

Soy desarrollador de software de **Berisso, Argentina**, y fundador de **IV Orbit Games**. Me interesa crear productos que combinen desarrollo de software, videojuegos, herramientas creativas y automatización mediante inteligencia artificial.

Disfruto trabajar tanto en la lógica como en la experiencia de usuario: desde sistemas y herramientas para desarrolladores hasta mundos interactivos y aplicaciones web.

- 🎮 **Game Development:** desarrollo de videojuegos y herramientas para Godot.
- 🌐 **Web Development:** aplicaciones, interfaces y sitios web modernos.
- 🤖 **IA & Automation:** agentes de IA, integración de modelos y herramientas basadas en MCP.
- 🧰 **Developer Tools:** creación de utilidades para mejorar flujos de trabajo.
- 🪐 **IV Orbit Games:** mi espacio para desarrollar y publicar proyectos propios.
